# Understanding mechanisms

Research proposals about the internal mechanisms supporting AI inference and how those mechanisms develop through training.

## First proposal

[Do learned world representations causally support novel inference?](proposals/causal-world-representations.md)

This proposed Othello-GPT reproduction and extension tests whether internal board-state representations help cause predictions on held-out positions. A later training comparison asks how such representations develop. Emergence and causation by training are compatible explanations, not alternatives.

**Status: proposed work; no experiments or results are published here.** The repository contains a research plan, not executable experimental code. It does not establish human–AI mechanistic equivalence or machine consciousness.

Proposed by [weiks](https://github.com/weiks), developed in discussion with OpenAI Codex, which assisted with research design and drafting. Andy Masley's essay motivates the question; he did not propose or endorse this experiment.
